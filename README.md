# alexkander.dev

Source code for the personal website of Alexander Rondón, built with Astro and MDX. Published at [alexkander.dev](https://alexkander.dev) (self-hosted) and mirrored at [alexkander.github.io](https://alexkander.github.io).

## Quick start

```sh
pnpm install
pnpm dev
```
