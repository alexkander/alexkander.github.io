# Documentation structure

- All documentation lives in `docs/`, split into one file per topic.
- `README.md` and `CLAUDE.md` stay short: they only introduce the repo and link to (or import) the relevant files in `docs/`.
- When adding new information, put it in the matching `docs/` file or create a new one, then reference it from `README.md` and/or `CLAUDE.md`.
